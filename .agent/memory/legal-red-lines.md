No art, audio, models, card names, character names or flavour text extracted or imitated from Gwent
or *The Witcher*; and no code decompiled or disassembled from an official client. Contributions
breaking either rule are closed without discussion. Full detail, including the accepted/not-accepted
lists, is in `../context/04-legal.md`.

**Why:** this is what lets an unofficial reimplementation exist in public at all. Mechanics are not
copyrightable; a specific expression of them is — so the project can rebuild how the game behaves,
but never copy how someone else wrote it down.

**How to apply:** never generate card or character names resembling Witcher/Gwent material; never
fetch or read decompiled clients, asset dumps or datamined card databases, and decline such requests
with the public-source alternative; record the public source for a rules change in the commit body;
ask when unsure rather than assuming it is fine. See [[licensing-split]].
