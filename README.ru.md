Открытая неофициальная реализация правил «Гвинта» — построена вокруг независимого от движка ядра
правил, с детерминированными реплеями и авторитарным сервером в мультиплеере.

> Это неофициальная фанатская работа, не одобренная и не поддерживаемая CD PROJEKT RED.

## Зачем это нужно

Официальная разработка контента для «Гвинта» завершена, но его ключевой дизайн — отсутствие кривой
стоимости, три ряда, матч до двух побед и темповая борьба вокруг вопроса *когда пасовать* — до сих
пор остаётся одним из самых интересных в жанре карточных игр. open-gwt продолжает этот дизайн в виде
открытого кода: играть, изучать, форкать и расширять его может кто угодно.

## Принципы разработки

- **Ядро правил, независимое от движка.** Все правила живут в чистой библиотеке без зависимостей от
  движка. Unity — это слой отрисовки и ввода, но никогда не место, где решаются правила.
- **Детерминированные реплеи.** Матч — это сид плюс упорядоченный список действий. Повторное
  проигрывание этого журнала в точности воспроизводит матч, благодаря чему становятся практичными
  тесты, отчёты об ошибках и боты.
- **Авторитарный сервер в мультиплеере.** Клиент отправляет намерения и отображает состояние,
  которое получает в ответ. Скрытая информация (руки, колоды, будущие добираемые карты) никогда не
  покидает сервер.

## Платформы

Windows · macOS · iOS · Android, на базе Unity 6.6 (6000.6.2f1).

## Структура репозитория

```
client/   проект Unity — тонкий клиент; открывайте этот каталог через Unity Hub
server/   авторитарный игровой сервер на Python — ядро правил находится внутри него
data/     карты, колоды и переводы в формате YAML
docs/     решения (adr/), протоколы (protocol/), описания правил
```

## С чего начать

- **Сначала прочитайте:** `docs/adr/` — записи архитектурных решений, `docs/protocol/` — протоколы
  карт и матча.
- **Работа над сервером:** код находится в каталоге `server/`, Python 3.12 или новее. Ядро правил,
  боты и симулятор — пакеты внутри него.
- **Работа над клиентом:** откройте каталог `client/` через Unity Hub, версия Unity 6.6 (6000.6.2f1).
  Клиент не выполняет никаких правил, и ему нужен запущенный сервер — даже для матча против бота.

## Как внести вклад

Мы рады вкладу любого рода: правила, эффекты карт, боты для матчей, клиент, документация и
оригинальные иллюстрации. Два правила обеспечивают юридическую чистоту проекта и не обсуждаются:

1. **Никаких материалов CD PROJEKT RED.** Пул-реквесты с изображениями, звуком, моделями,
   названиями карт, именами персонажей или флейвор-текстами, извлечёнными или скопированными из
   «Гвинта» или «Ведьмака», будут закрыты.
2. **Только чистая реализация (clean room).** Реализуйте функции по публичным описаниям правил и по
   наблюдаемому поведению игры. Не присылайте код, полученный декомпиляцией или дизассемблированием
   официального клиента.
