# Fonts

Noto Sans, Noto Sans SC, Noto Serif and Noto Serif SC, from the Google Fonts repository
(https://github.com/google/fonts, directories `ofl/notosans`, `ofl/notosanssc`, `ofl/notoserif`,
`ofl/notoserifsc`), licensed under the SIL Open Font License 1.1 — see the `OFL-*.txt` files here.
They are third-party assets, not covered by this repository's CC BY 4.0 for original assets.

What is checked in are **static instances subset from the variable fonts** to keep the repository
small (`server/scripts/fonts.py` documents the exact steps):

| File | Instance | Subset |
| --- | --- | --- |
| `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf` | wght 400 / 700, wdth 100 | Latin, Latin Extended, Greek, Cyrillic, punctuation, symbols |
| `NotoSerif-Regular.ttf`, `NotoSerif-Bold.ttf` | wght 400 / 700, wdth 100 | same |
| `NotoSansSC-Regular.ttf`, `NotoSerifSC-Regular.ttf` | wght 400 | GB 2312 plus CJK punctuation, fullwidth forms, and every character used in `data/i18n/zh-CN` |

The `*-SDF.asset` font assets next to them are generated by `OpenGwt.Editor.FontSetup.Run` as
dynamic SDF atlases; the fallback chain is Sans → Sans SC and Serif → Serif SC → Sans → Sans SC
(ADR 0006). Adding a language later means adding its Noto font to the chain.
